Kebijakan Hak Akses

Kebijakan ini menetapkan batas tindakan setiap role di Project Management System Prasasti Group. Akses diberikan sesuai tanggung jawab kerja, bukan berdasarkan permintaan lisan.

1. Empat role

  • User — membuat project dan menjalankan project yang dipegangnya dari Lead Masuk sampai Deal, termasuk mengunggah dokumen untuk project tersebut.
  • Finance — melengkapi dokumen dan nominal deal. Tidak dapat memindah tahap atau mengubah data project.
  • Manager — mengelola seluruh project dan client, termasuk Tidak Deal, memulihkan project, dan menghapus project ke Tempat Sampah.
  • Admin — seluruh akses Manager, ditambah mengelola akun dan role, Master Data, backup, pulihkan data, dan reset data.

2. Batas PIC project

Role User hanya dapat mengubah project yang tercantum namanya sebagai PIC. Tindakan yang dibatasi: edit data, lanjut ke Proses QL, ubah status QL, jadikan Deal, dan kelola dokumen. Manager dan Admin tidak terikat batas PIC.

3. Aksi khusus Admin

  • Membuat, mengubah, menonaktifkan, dan mengaktifkan kembali akun karyawan.
  • Menentukan role. Admin terakhir tidak boleh diturunkan atau dinonaktifkan.
  • Mengubah Master Data: tipe project, kategori, entitas, dan sumber lead.
  • Backup dan pulihkan data, mengosongkan Tempat Sampah, serta reset seluruh data dengan password khusus.
  • Menghapus permanen project dari Tempat Sampah.

4. Tombol yang tidak diizinkan

Tombol yang tidak tersedia bagi role Anda tetap ditampilkan dalam keadaan mati dengan keterangan role yang dibutuhkan. Ini bukan undangan untuk mencari celah. Dilarang memakai akun orang lain, mengubah kode aplikasi untuk menaikkan role, atau mengakses data lokal pengguna lain.

5. Perubahan role

Perubahan role hanya dapat dilakukan Admin dari halaman Karyawan dan harus sesuai penugasan resmi. Pengguna yang pindah tugas atau berhenti harus segera dinonaktifkan. Akun nonaktif tidak dapat masuk, tetapi nama dan riwayatnya tetap melekat pada project lama.

6. Akuntabilitas

Setiap perubahan penting tercatat di riwayat audit beserta nama pengguna dan waktu. Dilarang menghapus atau memanipulasi riwayat tersebut. Pelanggaran hak akses dapat dikenai tindakan disipliner sesuai aturan internal Prasasti Group.
