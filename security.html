Kebijakan Keamanan Informasi

Kebijakan ini mengatur cara pengguna menjaga keamanan data di Project Management System Prasasti Group. Aplikasi berjalan di browser perangkat pengguna, bukan di server, sehingga keamanan perangkat dan profil browser menjadi tanggung jawab pengguna.

1. Prinsip utama

  • Gunakan aplikasi hanya pada perangkat dan profil browser yang Anda miliki atau yang sudah diizinkan perusahaan.
  • Kunci layar perangkat saat meninggalkan meja. Jangan biarkan orang lain membuka aplikasi dengan akun Anda.
  • Jangan memakai komputer publik atau browser bersama untuk mengakses data project dan client.
  • Data bersifat internal. Dilarang memfoto, menyalin, atau membagikan data ke luar kebutuhan kerja tanpa izin.

2. Tempat data disimpan

Metadata akun, project, dan client tersimpan di localStorage browser. Berkas dokumen tersimpan di IndexedDB pada perangkat yang sama. Tidak ada server Prasasti Group yang menyimpan salinan data ini. Membersihkan data situs, menghapus profil browser, mengganti perangkat, atau kerusakan perangkat dapat menghilangkan data secara permanen.

Beberapa tab browser yang membuka alamat yang sama dapat saling sinkron, tetapi perangkat berbeda tidak saling bertukar data. Jangan menganggap aplikasi ini sebagai penyimpanan utama satu-satunya.

3. Akun dan sesi

  • Sesi tidak berhenti otomatis karena waktu. Keluar terjadi saat Anda menekan tombol Keluar atau saat Admin menonaktifkan akun.
  • Setelah lima kali gagal masuk dalam 5 menit, form login dikunci sementara.
  • Selalu klik Keluar bila selesai memakai perangkat bersama. Menutup tab mengakhiri sesi bila "Tetap masuk" tidak dicentang.
  • Lihat juga Kebijakan Akun & Password.

4. Cadangan dan pemulihan

Admin dapat mengekspor seluruh data dan berkas ke satu file backup JSON lewat tombol Backup Data di sidebar. Simpan file backup di lokasi yang diizinkan perusahaan dan uji pemulihannya secara berkala. Backup yang tidak diuji tidak dapat diandalkan.

5. Batasan perlindungan

Hak akses dan validasi di aplikasi ini ditegakkan di sisi klien. Orang yang menguasai perangkat dan profil browser secara teknis dapat melihat data lokalnya. Karena itu, gunakan akun sistem operasi yang terlindungi dan jangan memasang ekstensi browser yang tidak dipercaya.

6. Insiden dan pelaporan

Segera laporkan ke Admin jika perangkat hilang, akun terlihat dipakai orang lain, data tampak berubah tanpa sebab, atau berkas tersimpan di lokasi tidak resmi. Pengguna dilarang menghapus jejak atau mengubah data sebagai bentuk penutupan insiden.

7. Pelanggaran

Pelanggaran kebijakan ini dapat dikenai tindakan disipliner sesuai aturan internal Prasasti Group. Kebijakan ini dapat diperbarui; tanggal di bagian atas menunjukkan versi yang berlaku.
